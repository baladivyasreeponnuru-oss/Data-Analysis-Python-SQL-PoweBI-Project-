# 🛍️ Customer Shopping Behavior Analysis

### Data Analytics Project | Python • PostgreSQL • SQL • Power BI

## 📌 Project Overview

Customer Shopping Behavior Analysis is an end-to-end Data Analytics project that explores customer purchasing patterns, shopping preferences, discounts, subscriptions, and revenue.

This project uses Python for data cleaning and exploratory data analysis, PostgreSQL for database management, SQL for business analysis, and Power BI for data visualization.

The objective is to transform raw customer shopping data into meaningful insights that help businesses understand customer behavior and make better decisions.

## 🎯 Project Objectives

- Analyze customer purchasing behavior.
- Identify revenue patterns across customer segments.
- Understand the impact of discounts on purchases.
- Compare subscribed and non-subscribed customer spending.
- Analyze product ratings and shopping preferences.
- Segment customers based on previous purchases.
- Develop an interactive Power BI dashboard.

## 🔄 Project Workflow

### 1. Data Preparation – Python

- Imported and explored the dataset.
- Checked data types and missing values.
- Cleaned and prepared data for analysis.

### 2. Database Management – PostgreSQL

- Connected to PostgreSQL.
- Imported the customer shopping dataset.
- Created and managed the customer table.

### 3. Business Analysis – SQL

Developed 10 SQL queries to answer business questions:

1. Revenue generated by male and female customers.
2. Customers who used discounts but spent above average.
3. Top 5 products by average review rating.
4. Average purchase amount by shipping type.
5. Spending comparison between subscribers and non-subscribers.
6. Top 5 products by discount purchase percentage.
7. Customer segmentation into New, Returning, and Loyal.
8. Top 3 purchased products within each category.
9. Subscription behavior of repeat buyers.
10. Revenue contribution by age group.

### 4. Data Visualization – Power BI

- Designed an interactive dashboard.
- Presented important customer and sales metrics.
- Used charts and visualizations to communicate insights.
